# Models

Model weights are not tracked in this repo. Download them to this directory before training.

## Required Models

### Qwen3-1.7B-Base
```bash
huggingface-cli download Qwen/Qwen3-1.7B-Base \
  --local-dir models/Qwen3-1.7B-Base
```

models/
