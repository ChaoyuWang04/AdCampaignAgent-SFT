# 仓库使用指南

## 1. 仓库结构

当前仓库按职责分为以下区域：

- `data/raw/`
  - 原始生成样本。
- `data/intermediate/`
  - 中间转换产物。
- `data/processed/`
  - 训练和评测直接使用的数据集。
- `models/`
  - 本地模型权重和训练输出目录。
- `src/datapipeline/`
  - 数据生成、切分、转换、合并脚本。
- `src/tools/`
  - 旅行助手运行时工具实现。
- `src/inference/`
  - 旅行助手运行时主逻辑。
- `src/train/`
  - 训练、检查、LoRA 合并脚本。
- `src/common/`
  - 公共模块和路径工具。
- `tests/`
  - 手动运行的测试/验证脚本。
- `scripts/`
  - 训练启动 shell 脚本。
- `rag-system/`
  - 独立 RAG 子系统。

---

## 2. 关键数据与模型位置

### 数据目录

- 原始样本：
  - `data/raw/travel_assistant_dataset_20250914_112354.json`
- 切分后的训练/测试集：
  - `data/processed/travel_assistant_train_dataset.json`
  - `data/processed/travel_assistant_test_dataset.json`
- 转换后的批次文件：
  - `data/intermediate/converted_train/*.json`

  - `data/ready2train/message/ad_agent_sft_<timestamp>_<lang>_message.json`

  - `data/processed/merged_test_final.json`

### 模型目录

- 基础模型：
  - `models/qwen3-0_6b/`
- 训练输出默认目标：
  - `models/qwen3-0_6b_lora_last_assistant/`
  - `models/qwen3-0_6b_fullft_last_assistant/`
  - `models/qwen3-0_6b_merged/`

### 工具 Schema

- `src/tools/all_tools.json`

## 3. 运行前提

以下脚本依赖本地或外部资源，不满足条件时不会正常运行：

- 训练脚本：
  - 依赖 `torch`、`transformers`、`peft`、`trl`。
- 推理脚本：
  - 依赖 `openai`、本地模型文件、可选的 RAG API 服务。
- 工具脚本：
  - 酒店工具依赖 `openai` 兼容接口。
  - 路线工具依赖高德 API。
  - 天气工具依赖和风天气 API。
- RAG 脚本：
  - 依赖 `flask`、`pymilvus`、`jieba`、`openai`。

## 4.2 `src/datapipeline/`

### `src/datapipeline/generate_dataset.py`

- 作用：规则生成原始旅行助手样本。
- 运行方式：
  - `python src/datapipeline/generate_dataset.py`
- 输入：
  - 无命令行输入，脚本内置城市、问题模板和工作流比例。
- 输出：
  - 在当前工作目录生成一个 JSON 文件。
- 输出文件形式：
  - JSON 数组。
- 默认输出文件名：
  - `travel_assistant_dataset_<timestamp>.json`
- 建议输出位置：
  - 运行后手动移动到 `data/raw/`，或在后续再参数化。

### `src/datapipeline/split_dataset.py`

- 作用：将原始样本切分为训练集和测试集。
- 运行方式：
  - `python src/datapipeline/split_dataset.py`
- 输入：
  - 原始样本 JSON。
- 输出：
  - 训练集 JSON
  - 测试集 JSON
- 输出文件形式：
  - JSON 数组。
- 备注：
  - 该脚本当前仍是脚本内固定逻辑，适合后续补命令行参数。

### `src/datapipeline/convert_dataset.py`

- 作用：将原始样本转换为带工具调用轨迹的对话训练数据。
- 运行方式：
  - `python src/datapipeline/convert_dataset.py <input_json_file> [output_dir]`
- 输入：
  - `input_json_file`：原始样本 JSON 数组。
  - `output_dir`：输出批次目录。
- 输出：
  - 分批转换后的 JSON 文件。
- 输出文件形式：
  - 多个 `converted_batch_*.json`
  - 每个文件内容为 JSON 数组。
- 推荐输入位置：
  - `data/processed/travel_assistant_train_dataset.json`
  - `data/processed/travel_assistant_test_dataset.json`
- 推荐输出位置：
  - `data/intermediate/converted_train/`
  - `data/intermediate/converted_test/`

### `src/datapipeline/merge_json_files.py`

- 作用：合并分批转换结果，生成完整训练集和测试集。
- 运行方式：
  - `python src/datapipeline/merge_json_files.py`
- 默认输入：
  - `data/intermediate/converted_test/*.json`
  - `data/intermediate/converted_train/*.json`
- 默认输出：
  - `data/processed/merged_test_final.json`
  - `data/processed/merged_train_final.json`
- 输入文件形式：
  - JSON 数组文件。
- 输出文件形式：
  - JSON 数组文件。

### `src/datapipeline/conversation_splitter.py`

- 作用：将 `message` 格式对话数据按 assistant 轮次拆分，扩展成多轮训练样本。
- 运行方式：
  - `python src/datapipeline/conversation_splitter.py`
- 运行时输入：
  - 手动输入要处理的 JSON 文件名。
- 默认查找目录：
  - `data/ready2train/message/`
- 默认输出：
  - 与输入文件同目录，文件名追加 `_multiturn`。
- 输入文件形式：
  - JSON 数组，每项含 `messages` 字段。
- 输出文件形式：
  - JSON 数组。

## 4.3 `src/tools/`

### `src/tools/get_hotel.py`

- 作用：生成酒店推荐和酒店评价。
- 主要函数：
  - `get_hotel_recommendations(user_requirements, model_name)`
  - `get_hotel_reviews(hotel_name, model_name)`
- 输入：
  - 用户酒店需求字符串
  - 酒店名字符串
- 输出：
  - Python 列表，列表元素为字典。
- 输出数据形式：
  - 酒店推荐：`List[Dict]`
  - 酒店评价：`List[Dict]`
- 文件输入输出：
  - 无固定文件输入输出。

### `src/tools/get_route.py`

- 输入：
  - 起点坐标字符串
  - 终点地名字符串

- 输出：
  - 路线结果字典。
- 文件输入输出：
  - 无固定文件输入输出。

### `src/tools/get_weather.py`

- 作用：通过天气 API 查询指定日期或日期范围的天气。
- 主要函数：
  - `get_weather_by_date_range(location, start_date, num_days)`

- 输入：
  - 城市 ID 或坐标
  - 日期

- 输出：

- 文件输入输出：

### `src/tools/all_tools.json`

## 5. 推荐使用顺序

如果要从零复现数据和训练流程，推荐顺序如下：

1. 生成原始样本：
   - `python src/datapipeline/generate_dataset.py`
2. 切分训练/测试：
   - `python src/datapipeline/split_dataset.py`
3. 转换为带工具调用轨迹的对话：
   - `python src/datapipeline/convert_dataset.py <input> <output_dir>`
4. 合并批次：
   - `python src/datapipeline/merge_json_files.py`
5. 拆分成多轮训练数据：
   - `python src/datapipeline/conversation_splitter.py`
6. 检查训练数据：
   - `python src/train/inspect_qwen_dataset.py`
7. 启动训练：
   - `bash scripts/run_train_last_assistant.sh`
   - 或 `bash scripts/run_train_full_finetune.sh`
8. 合并 LoRA：
   - `python src/train/merge_lora_into_base.py`
9. 本地推理验证：
   - `python tests/inference/test_qwen_infer.py`
10. 运行旅行助手：
   - `python src/inference/travel_assistant_funcall_fixed.py`
